# Генератор осмысленного текста на естественном языке

Семантический анализатор [Lab-4](../Lab-4/README.md) дополнен генерацией текста
по результатам анализа. Используются **Seq2Seq LSTM** и грамматические шаблоны;
связи, части речи и факты извлекаются через **spaCy** и регулярные выражения.


## Архитектура и принцип работы

Текст разбирается теми же слоями, что и в Lab-4, после чего из признаков собирается описание:

1. **Тональность (TextCNN)** - класс `positive` / `negative` / `neutral` и уверенность модели;
2. **Тема (LSA / TruncatedSVD)** - доминирующая тема и ее термины;
3. **Ключевые леммы (TF-IDF)** - термины с наибольшим весом;
4. **Ассоциации (Word2Vec)** и ближайшая формулировка корпуса (Doc2Vec);
5. **Связи и части речи (spaCy)** - предикативные основы «субъект - действие - объект»
   и сочетания «прилагательное + существительное»;
6. **Факты** - сущности, которые не выводятся из частеречного разбора:
   суммы, количества, даты, время, интервалы, сроки, дни недели, месяцы,
   проценты, телефоны, адреса, геометки, ссылки, почта и номера.


### Шаблоны

Признаки подставляются в фиксированные формулировки: тональность, ключевое высказывание,
тема, леммы, ассоциации, сочетания, близкий документ и извлеченные факты.
spaCy отвечает за разбор (`token.pos_`, `token.dep_`, `Matcher`) и именованные сущности;
регулярные выражения - за остальные факты. Пересечения отбрасываются, чтобы не дублировать
информацию.


### Sequence-to-Sequence LSTM

- **EncoderLSTM** - двунаправленный LSTM по леммам входного текста;
- **DecoderLSTM** - авторегрессионный LSTM со словарем команд (`<sentiment>`, `<relation>`,
   `<topic>`, `<keywords>`, `<conclusion>`, `<phrase>`, `<similar>`, `<facts>`);
- обучение через `CrossEntropyLoss` и teacher forcing: порядок команд зависит от типа текста.

Итоговый текст собирается из шаблонов в предсказанном порядке и нормализуется
(капитализация, пунктуация).


## Структура проекта

В директории [src](./src/) находятся:

- [Tokenizer](./src/tokenizer.py) - токенизация слов и чисел;
- [Normalizer](./src/normalizer.py) - стоп-слова, нижний регистр и лемматизация (pymorphy3);
- [Extractor](./src/extractor.py) - связи, части речи и факты (spaCy и регулярные выражения);
- [LSA](./src/lsa.py) - TF-IDF, TruncatedSVD, Word2Vec, Doc2Vec, TextCNN, шаблоны и Seq2Seq LSTM;
- [Train](./src/train.py) - обучение LSA, TextCNN и генератора;
- [Main](./src/main.py) - CLI анализа и генерации.

Обученная модель сохранена в `models/lsa.joblib`.


## Запуск

Запуск выполняется в **Docker**:

1. Сборка контейнера:

   ```bash
   docker build -t vv_lab5 .
   ```

2. Обучение модели (если необходимо):

   ```bash
   docker run --rm -v "${PWD}:/workspace" vv_lab5 python -m src.train
   ```

3. Анализ и генерация:

   ```bash
   docker run --rm -v "${PWD}:/workspace" vv_lab5 python -m src.main
   ```

   Нужен `--text "<текст>"` или `--file <путь>`. Файл должен лежать в текущей
   директории: она монтируется в контейнер. Каждая непустая строка файла - отдельный документ.
   
   Примеры:

   ```bash
   docker run --rm -v "${PWD}:/workspace" vv_lab5 python -m src.main --text "Фильм оказался скучным и затянутым"
   docker run --rm -v "${PWD}:/workspace" vv_lab5 python -m src.main --file example.txt
   ```

4. Очистка:

   ```bash
   docker rmi vv_lab5
   ```

Для каждого документа печатается полный блок разбора, разделенного по разделам.
